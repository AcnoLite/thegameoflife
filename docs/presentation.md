# Présentation orale — The Game of Life (27 nov, 13h30, ≤ 20 min)

## Script de démo

1. **Accueil (2 min)** — présenter le projet IUT : un site statique sur le Jeu de la vie de Conway, hébergé sur alwaysdata. Montrer la page Histoire puis les Règles.
2. **Démo du jeu (8 min)** — ouvrir `game.html` :
   - cliquer sur des cases pour dessiner un motif à la main ;
   - appuyer sur **Planeur** pour poser le vaisseau au centre ;
   - lancer avec **Démarrer**, régler la vitesse avec le curseur ;
   - montrer **Pas à pas**, **Hasard**, **Effacer** ;
   - changer de thème avec le bouton « Changer de style ».
3. **Vidéo embarquée (2 min)** — lire la démonstration vidéo intégrée en bas de la page du jeu, sous-titrée en français.
4. **Formulaire (2 min)** — aller sur `feedback.html`, remplir et envoyer un avis.
5. **Aspects techniques (4 min)** — moteur du jeu copié depuis `conway-game-of-life-js` (MIT, Matthew Ruten), pages statiques, W3C valide, deux thèmes CSS, déploiement par `git pull` sur le serveur.
6. **Conclusion (2 min)** — questions.

## Sources

- Moteur du jeu : <https://github.com/nomatteus/conway-game-of-life-js> (Matthew Ruten, 2012, licence MIT)
- Règles du Jeu de la vie : John Horton Conway, 1970
- Polices : Fraunces et Instrument Sans (Google Fonts, licences Open Font)
- Vidéo de démonstration générée avec le filtre `life` de FFmpeg
